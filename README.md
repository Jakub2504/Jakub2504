## Selected work

### [als-voice-biomarkers](https://github.com/Jakub2504/als-voice-biomarkers) — Bachelor's thesis, graded 10/10
An end-to-end system that analyses voice recordings to support the monitoring of **ALS**
(amyotrophic lateral sclerosis):

- **Machine learning** — 205 acoustic biomarkers, 6 models compared, stratified
  cross-validation, Optuna tuning. Best result: **0.910 AUC-ROC** (bulbar vs non-bulbar).
- **Explainability** — SHAP down to the individual biomarker, so every prediction
  can be inspected.
- **LLM** — Llama-3.3-70B drafts a structured clinical report grounded only in the
  model's own numbers.
- **Software** — FastAPI REST API and a web portal; the thesis also included an
  Android app for at-home follow-up.

A research **support** tool, not a diagnostic product — the limitations are documented
openly in the repository.
